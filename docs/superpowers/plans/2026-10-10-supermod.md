# SuperMod Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Claude Code mod named `supermod` that draws a band above the prompt and a `/supermod` pane showing Superpowers run progress (overall and per step, with station credit per task), the main context window fill with thresholds, the session's agents with token usage, cost, and a remaining-time range, on terminal and Desktop, with a text fallback elsewhere, published as a public MIT marketplace repo under `github.com/siller/supermod`.

**Architecture:** One hooks module (`hooks/register.tsx`) observes engine events and timers and writes a snapshot into `$.state`; pure TypeScript modules (`progress.ts`, `scan.ts`, `usage.ts`, `eta.ts`, `i18n.ts`, `prices.ts`) hold every rule and are unit-tested without the engine; two render modules (`band.tsx`, `pane.tsx`) turn the snapshot into width-planned trees. The mod reads only Superpowers' plan, spec, ledger and workspace listings inside the repository's search roots and calls nothing else.

**Tech Stack:** Claude Code mods API (function hooks, early access, tested on 2.1.296), TypeScript/TSX loaded directly by Claude Code (no build step, no dependencies), `claude plugin validate` and `claude plugin test` (test kit `claude-code/testing`), GitHub Actions for validate and tests.

**Spec:** `docs/superpowers/specs/2026-10-10-supermod-design.md`

## Global Constraints

- Plugin name `supermod`; `plugin.json` has `version`, `description`, `author { name: "Mark Siller", url: "https://github.com/siller" }`, `license: "MIT"`, `types: "./types/index.d.ts"`.
- The validator's `calls:` line may list only: `$.command.register`, `$.ui.open`, `$.ui.close`, `$.ui.resolve`, `$.ui.toast`, `$.ui.panes`, `$.session.usage`, `$.session.surfaces`, `$.session.root`, `$.agent.list`, `$.clock.now`, `$.clock.every`, `$.clock.after`, `$.fs.read`, `$.fs.stat`, `$.fs.list`, `$.state.get`, `$.state.set` (the last two appear via `read`/`update`). No `env reads:` line may appear. CI fails on any other call.
- Every `$` call is written in full (`$.fs.read(...)`) in `register.tsx` or in a top-level function of the same file that receives `$`; pure modules never receive `$`.
- Every observing hook returns `next(e)` unchanged; only `command.run{command=supermod}` answers for itself.
- File reads only on `docs/superpowers/plans/*.md`, `docs/superpowers/specs/*-design.md`, `.superpowers/sdd/*/progress.md`, `.superpowers/sdd/*/plan-path`; listings only on `docs/superpowers/plans/`, `docs/superpowers/specs/`, `.superpowers/sdd/`, `.superpowers/sdd/<plan>/`, `.claude/worktrees/`, `.worktrees/`, `worktrees/`; all under the search roots of the spec §5.1; a path whose `realPath` leaves the roots is refused.
- Labels only from `i18n.ts`; `language` option `en` (default) or `de`.
- Thresholds: `warnPercent` default 70, `criticalPercent` default 85; `showCost` default true; `reviewMinutes` default 10.
- Step weights: Brainstorming 5, Spec 10, Plan 10, Tasks 60, Review 10, Finish 5. Station credit: brief 15, implementer 40, review 70, fix round 85, complete 100. Range factors 0.7 and 1.5. History ring 30 readings. Agent rows cap 200.
- No row drawn in the band or the pane may be wider than `e.props.bodyColumns`. Band degradation order: time range, agent count, task station, plan title.
- Number format: `1.2M`, `381k`, plain integers below 1000; no locale separators.
- No reference to the author's employer anywhere; all `gh` calls use `GH_HOST=github.com` or `--repo siller/supermod`.
- Commit after every task with a conventional message (`feat:`, `test:`, `docs:`, `chore:`).

## Review Focus

1. A ledger line such as `Task 3: parked — review clean? Ruling: complete later` must not count as a station; only text directly after `Task N:` matching `complete` or `fix round` does. Test in Task 3.
2. A plan file over 1 MiB or a ledger that the engine refuses to read (over 4 MiB) must leave the last snapshot standing, not blank the band. Test in Task 6.
3. A symlink inside `.superpowers/sdd/` pointing outside the repository must be refused and never read. Test in Task 6.
4. Resume of a session: `$.state` restored by the engine and no completions observed yet must show progress but "not enough data" for the time range, not a wrong estimate. Test in Task 8.
5. A toast must fire once per upward crossing and again only after the fill dropped below the threshold; a reading that jumps from 60 to 90 fires one toast (critical), not two. Test in Task 7.
